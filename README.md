## ⚡ Highlights

* ⏱️ **Interactive Live Rest Timer**: Automatically triggers countdown alerts (90s, +15s, -15s) when sets are logged.
* 🏋️‍♂️ **Set & Rep Logger**: Fast logging of weight (kg/lbs), previous performance, and target reps.
* 🎯 **1RM Calculator**: Instant one-rep max estimation powered by the Epley and Brzycki formula.
* 🗺️ **Muscle Fatigue Radar**: Track weekly volume and recovery status across major muscle groups.
* 📱 **Mobile & Desktop Ready**: Beautiful responsive dark-mode UI designed for use directly on your phone at the gym.

## 🚀 Quick Start

Open `index.html` in any browser or launch a local server:

```bash
# Clone the repository
git clone https://github.com/carloseduardoscsouza-dot/titan-gym.git
cd titan-gym

# Open in browser directly
# On Windows:
start index.html
# Or run with Python:
python -m http.server 8080
```
